# Моя история

MVP сервиса, который превращает ответы на вопросы в автобиографию-книгу.

- **Лендинг** — `#/`
- **Интервью** — `#/interview`: 9 глав, ответы текстом или голосом (Web Speech API, Chrome/Safari), варианты-подсказки, уточняющие вопросы, фото к главе.
- **Книга** — `#/book`: обложка, содержание, главы; кнопка «Скачать PDF» (A5, html2pdf.js).
- **Пример** — `#/example`.

Статический сайт без сборки и бэкенда: ответы хранятся в `localStorage` браузера.

## Локальный запуск

```bash
python3 -m http.server 5173
```

## Деплой

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`. Каждый пуш в `main` обновляет сайт.
