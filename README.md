# Моя история

**Интервью с самим собой.** Твоя автобиография за один час: отвечаешь на вопросы голосом или текстом — получаешь книгу своей жизни в PDF.

- **Лендинг** — `#/`
- **Интервью** — `#/interview`: 60 вопросов в 10 главах, ответы текстом или голосом (Web Speech API, Chrome/Safari), варианты-подсказки, уточняющие вопросы, фото к главе.
- **Книга** — `#/book`: обложка, содержание, главы; кнопка «Скачать PDF» (A5, html2pdf.js).
- **Пример** — `#/example`.

Статический сайт без сборки и бэкенда: ответы и место, где человек остановился, сохраняются в `localStorage` на каждый ввод — можно закрыть вкладку и продолжить с того же вопроса (на том же устройстве и в том же браузере).

## Локальный запуск

```bash
python3 -m http.server 5173
```

## Деплой

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`. Каждый пуш в `main` обновляет сайт.
