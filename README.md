# Книга моей жизни

**Интервью с самим собой.** Человек отвечает на вопросы голосом или текстом и получает автобиографию в PDF. Модель: бесплатная короткая версия и полная книга за единоразовую оплату.

## Что есть

- **Лендинг** — `#/`: оффер, путь пользователя, 10 глав, тарифы.
- **Моя история (бесплатно)** — `#/free`: 12 вопросов в 5 разделах → короткая автобиография с названием.
- **Предложение** — `#/offer`: текст из ТЗ, 1 490 ₽ единоразово. Оплата пока не подключена: кнопка честно говорит, что это тест, и открывает полную версию бесплатно. Клики пишутся в `state.events` (`offer_view`, `buy_click`, `unlock`) — это заготовка для проверки спроса.
- **Полная книга** — `#/full`: 10 глав, 94 вопроса, фото к главам. Ответы бесплатной части вливаются в главы полной книги.
- **Уточнения** — после ответа система предлагает 1–2 уточняющих вопроса из списка ТЗ, выбирая по тому, чего в ответе не хватает (места и возраста, людей, чувств, развязки). ИИ пока нет: это правила в `js/questions.js`.
- **Книга** — `#/book`: чтение, редактор (название, автор, посвящение в полной версии, правка текста, выбор историй «в книге / не в книге»), PDF формата A5.
- **Пример** — `#/example`.

Вопросы — в `js/questions.js`. Шаблоны `{был|была}` подставляют форму по полу автора.

Статический сайт без сборки и бэкенда: ответы и место, где человек остановился, сохраняются в `localStorage` на каждый ввод — можно закрыть вкладку и продолжить с того же вопроса (на том же устройстве и в том же браузере).

## Аналитика

Яндекс Метрика подключается в `js/analytics.js`: впиши номер счётчика в `METRIKA_ID`. Пока там 0, Метрика не загружается. Вебвизор выключен — он записывал бы текст ответов.

Цели (в Метрике: «JavaScript-событие» с таким идентификатором):

| Идентификатор | Когда срабатывает |
|---|---|
| `free_finished` | нажал «Собрать мою историю» на 12-м вопросе |
| `offer_view` | открыл предложение полной книги |
| `buy_click` | нажал «Открыть полную версию» |

## Локальный запуск

```bash
python3 -m http.server 5173
```

## Деплой

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`. Каждый пуш в `main` обновляет сайт. Перед коммитом запусти `./bump-version.sh` — он меняет версию у CSS/JS, чтобы браузеры не показывали старые файлы из кэша.
